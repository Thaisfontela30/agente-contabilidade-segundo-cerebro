# 📤 Guia de Upload de Arquivos no GitHub

Este guia foi criado para ajudar na organização e publicação dos materiais do projeto no GitHub de forma profissional e organizada.

## 1. Estrutura recomendada

```text
agente-contabilidade-segundo-cerebro/
├── README.md
├── evidencias/
│   ├── cards/
│   ├── screenshots/
│   └── audios/
├── fontes/
│   ├── pdfs/
│   └── apresentacoes/
├── guia-upload.md
└── materiais-estudo/
```

## 2. Como subir arquivos pelo GitHub web

1. Acesse o repositório:
   https://github.com/Thaisfontela30/agente-contabilidade-segundo-cerebro

2. Clique em `Add file`

3. Escolha `Upload files`

4. Arraste os arquivos para a área de upload ou selecione-os no computador

5. No campo de mensagem, escreva uma descrição clara, por exemplo:
   - `Adiciona PDFs de referência e materiais do projeto`
   - `Adiciona screenshots e cards do NotebookLM`
   - `Adiciona apresentação e materiais de estudo`

6. Clique em `Commit changes`

## 3. Organização sugerida dos arquivos

### Evidências
Use a pasta `evidencias/` para:

- screenshots
- cards
- imagens de estudo
- áudios do NotebookLM

Exemplos:

```text
evidencias/
├── cards/
│   ├── card-dre.png
│   └── card-balanco-patrimonial.png
├── screenshots/
│   ├── print-chat-citacoes.png
│   └── print-consulta-notebooklm.png
└── audios/
    └── audio-explicacao-balanço.mp3
```

### Fontes
Use a pasta `fontes/` para:

- PDFs
- normas
- materiais oficiais
- apresentações

Exemplos:

```text
fontes/
├── pdfs/
│   ├── cpc-00-estrutura-conceitual.pdf
│   └── guia-irpj-lucro-presumido.pdf
└── apresentacoes/
    └── apresentacao-contabilidade-geral.pdf
```

## 4. Boas práticas profissionais

- Use nomes de arquivo em minúsculas
- Evite espaços e acentos
- Prefira hifens em vez de espaços
- Mantenha uma estrutura clara e organizada
- Sempre descreva o conteúdo dos arquivos no README

Exemplos corretos:

```text
cpc-00-estrutura-conceitual.pdf
print-chat-citacoes.png
card-dre.png
```

Exemplos inadequados:

```text
CPC 00.pdf
print chat.png
Card de DRE.png
```

## 5. Como registrar o material no README

No `README.md`, é interessante incluir links para os arquivos principais, por exemplo:

```markdown
## Evidências do projeto

- [Print do chat com citações](./evidencias/screenshots/print-chat-citacoes.png)
- [Card de Balanço Patrimonial](./evidencias/cards/card-balanco-patrimonial.png)
- [PDF de referência](./fontes/pdfs/cpc-00-estrutura-conceitual.pdf)
```

## 6. Dicas importantes

- O GitHub funciona melhor com arquivos bem organizados
- Mantenha o repositório limpo e profissional
- Use sempre uma mensagem clara no commit
- Evite deixar arquivos soltos na raiz do projeto

## 7. Mensagens de commit recomendadas

Exemplos:

- `Adiciona README inicial do projeto`
- `Organiza estrutura de evidencias e fontes`
- `Adiciona materiais de referência contábeis`
- `Inclui screenshots e cards do NotebookLM`

## 8. Conclusão

A organização correta dos arquivos no GitHub é essencial para deixar o projeto profissional, acessível e fácil de entender. A estrutura sugerida acima facilita a leitura e deixa o material pronto para apresentação ou compartilhamento.
