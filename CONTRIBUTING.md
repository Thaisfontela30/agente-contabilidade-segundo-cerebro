# Contribuindo

Obrigado por interessar-se em contribuir para este projeto.

## Como participar

1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração.
3. Mantenha a documentação clara e objetiva.
4. Faça commits com mensagens descritivas.
5. Abra um pull request com contexto do que foi ajustado.

## Padrões recomendados

- Priorize clareza e organização.
- Mantenha nomes de arquivos padronizados.
- Documente alterações relevantes no README ou em arquivos de apoio.
- Use linguagem técnica e objetiva, compatível com estudo profissional.
